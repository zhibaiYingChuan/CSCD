C-S-C-D：部署指南 + 效果看板

本页面无需输入任何内容。复制配置到你的工具即可完成部署，或向下滚动查看真实效果数据。

① 部署配置（一键复制）

复制到你的 MCP 客户端配置（Continue 的 mcp.json / Cline 的 cline_mcp_settings.json / Claude Desktop）。

{
  "mcpServers": {
    "cscd-protocol": {
      "command": "python",
      "args": ["cscd_mcp_server.py"],
      "cwd": "${workspaceFolder}/cscd",
      "env": {
        "LLM_API_URL": "${env:LLM_API_URL}",
        "LLM_API_KEY": "${env:LLM_API_KEY}",
        "LLM_MODEL": "${env:LLM_MODEL}"
      }
    }
  }
}

设置模型端点环境变量（任一组已配置即自动采用，与你的 AI 工具中已配置的 Key 一致）。

# 与你的 AI 工具共用同一个 Key 与模型，按需填写（不预设任何具体模型/端点）
export LLM_API_URL="https://你的模型服务地址"
export LLM_API_KEY="你的Key"
export LLM_MODEL="你的模型名"      # 如 gpt-4o / claude-... / deepseek-chat / 本地模型

# 或使用 OPENAI_*（OpenAI 兼容端点）
export OPENAI_BASE_URL="https://你的模型服务地址"
export OPENAI_API_KEY="你的Key"
export OPENAI_MODEL="你的模型名"

一键启动（推荐）：在 CSCD 仓库根目录执行。

# 在 CSCD 仓库根目录（含 start_services.py 的目录）
python start_services.py            # 检查依赖 + 端点就绪 + 接入指引
python start_services.py --all      # 一键启动 WebUI(8000) + REST API(8001)

# 打开看板
# http://127.0.0.1:8000
